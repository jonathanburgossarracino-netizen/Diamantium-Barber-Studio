# DIAMANTIUM BARBER STUDIO - App

Sistema web para la gestión de servicios, citas y administración de Diamantium Barber Studio.

## 🛠️ Tecnologías utilizadas
* HTML5
* CSS3
* JavaScript

## 🌿 Estructura de Ramas (Git Flow)
* `main`: Rama de producción / versión estable.
* `develop`: Rama de desarrollo principal.
* `feature/*`: Ramas secundarias para funcionalidades específicas.
